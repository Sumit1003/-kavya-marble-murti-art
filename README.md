- Prices on the site are indicative — final price is confirmed on WhatsApp.

## Deploy

This is a single self-contained static site. `index.html` is the whole website (all assets inlined).

- **Vercel:** Import this repo, framework preset: Other / Static, no build command, output directory: `.` (root).
- **Render:** New Static Site, build command: empty / none, publish directory: `.` (root).

No build step, no server, no environment variables needed.
